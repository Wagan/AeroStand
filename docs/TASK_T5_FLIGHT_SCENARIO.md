# TASK_T5_FLIGHT_SCENARIO — AeroStand: сценарий полёта (таймлайн углов)

## Контекст

T1–T4 закрыты и проверены на железе (dc56210). USB CDC работает (COM4), экран показывает углы, команды ANGLE/CAL/ZERO/HOME/ENABLE/DISABLE/STATUS/PING работают. Моторы пока не подключены (DRV8825 заказаны).

Следующий шаг — загрузить в стенд сценарий полёта: последовательность углов трёх рулевых поверхностей по времени. Стенд отрабатывает сценарий автоматически, студент наблюдает на экране (а потом и на реальных моторах).

## Что сделать

### 1. Структура сценария (scenario.c / scenario.h)

Сценарий — массив ключевых точек (keyframes). Каждая точка:
```c
typedef struct {
    uint32_t time_ms;    // время от начала сценария, мс
    float    angle[3];   // целевые углы трёх осей, градусы
} scenario_keyframe_t;
```

Между точками — линейная интерполяция. Если время между точками 0 — мгновенный переход.

Хранение: статический массив до 64 точек (SCENARIO_MAX_KEYFRAMES). Загружается по USB CDC.

Функции:
- `scenario_clear()` — очистить сценарий
- `scenario_add_keyframe(time_ms, angle0, angle1, angle2)` — добавить точку
- `scenario_start()` — запустить воспроизведение (вызывает ENABLE на всех осях)
- `scenario_stop()` — остановить воспроизведение
- `scenario_is_running()` — возвращает 1, пока сценарий выполняется
- `scenario_update()` — вызывается из while(1); по HAL_GetTick вычисляет текущие углы интерполяцией и вызывает stepper_move_to_angle для каждой оси

По окончании сценария (прошли все точки) — остановить, отправить `SCENARIO DONE\n` в USB.

### 2. Команды USB CDC (cmd_parser.c)

| Команда | Формат | Описание |
|---------|--------|----------|
| SCLEAR | `SCLEAR` | Очистить сценарий |
| SKEY | `SKEY <time_ms> <a0> <a1> <a2>` | Добавить ключевую точку |
| SRUN | `SRUN` | Запустить сценарий. Все оси автоматически ENABLE |
| SSTOP | `SSTOP` | Остановить сценарий |
| SCOUNT | `SCOUNT` | Ответ: `SCOUNT <n>\n` — количество загруженных точек |

Ответы:
- `OK\n` — команда принята
- `ERR FULL\n` — массив переполнен (64 точки)
- `ERR EMPTY\n` — SRUN при пустом сценарии
- `ERR VALUE\n` — неверные параметры
- `SCENARIO DONE\n` — сценарий завершён

Пример загрузки и запуска сценария (руль 0 качается ±15°, остальные в нуле):
```
CAL 0 5.5
CAL 1 5.5
CAL 2 5.5
ZERO 0
ZERO 1
ZERO 2
SCLEAR
SKEY 0 0.0 0.0 0.0
SKEY 1000 15.0 0.0 0.0
SKEY 2000 -15.0 0.0 0.0
SKEY 3000 15.0 0.0 0.0
SKEY 4000 -15.0 0.0 0.0
SKEY 5000 0.0 0.0 0.0
SRUN
```

### 3. Обновить LCD

Когда сценарий работает, показывать в заголовке:
```
AeroStand v0.1  PLAY 03.2s
```
где 03.2s — текущее время в сценарии. Когда не работает — как раньше.

### 4. Обновить STATUS

Добавить строку после трёх осей:
```
SCENARIO <state> <keyframes> <time_ms>\n
```
где state = IDLE / PLAYING, keyframes — количество точек, time_ms — текущее время (0 если IDLE).

## Частота обновления

scenario_update() вызывается из while(1) — по сути каждый тик. Но stepper_move_to_angle не запустит новое движение, пока текущее не завершилось. Поэтому фактическая частота обновления углов определяется частотой шагов (freq_hz в ANGLE). По умолчанию 500 Гц, для коротких переходов (единицы шагов) это единицы миллисекунд — достаточно плавно.

Интерполяция: scenario_update рассчитывает целевой угол и вызывает stepper_move_to_angle. Если ось занята предыдущим движением, новый угол запоминается и применяется, когда ось освободится (на следующем проходе цикла).
