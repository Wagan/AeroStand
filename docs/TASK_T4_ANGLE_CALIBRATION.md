# TASK_T4_ANGLE_CALIBRATION — AeroStand: позиционирование в градусах и калибровка

## Контекст

T1–T3 закрыты и проверены на железе (ef7188d). USB CDC работает (COM4), экран показывает состояние осей, команды MOVE/ENABLE/DISABLE/STATUS/PING работают. Моторы пока не подключены (платы MP1510+MP8825 в пути).

Задача стенда — управлять рулевыми поверхностями оперения планера. Ходы короткие (единицы–десятки градусов), нужна команда в градусах, а не в шагах. Для пересчёта градусов в шаги нужна калибровка — передаточное отношение (шагов на градус) зависит от механики машинки коллег.

## Что сделать

### 1. Калибровочные параметры (stepper.h / stepper.c)

Для каждой оси хранить:
- `steps_per_degree` — коэффициент пересчёта (float, по умолчанию 1.0)
- `angle_min_deg`, `angle_max_deg` — допустимый диапазон углов (float, по умолчанию -90.0 и +90.0)
- `zero_offset_steps` — смещение нуля в шагах (int32_t, по умолчанию 0)

Функции:
- `stepper_set_calibration(axis, steps_per_degree)` — задать коэффициент
- `stepper_set_limits(axis, min_deg, max_deg)` — задать допустимый диапазон
- `stepper_set_zero(axis)` — текущую позицию считать нулём (нейтраль руля)
- `stepper_move_to_angle(axis, angle_deg, freq_hz)` — переместить ось в заданный угол. Вычислить целевую позицию в шагах = angle_deg × steps_per_degree + zero_offset, найти разницу с текущей позицией, вызвать stepper_move с нужным количеством шагов и направлением
- `stepper_get_angle(axis)` — текущий угол (float)

Проверка границ: если angle_deg вне [min, max], вернуть ошибку, не двигать.

### 2. Команды USB CDC (cmd_parser.c)

| Команда | Формат | Описание |
|---------|--------|----------|
| ANGLE | `ANGLE <axis> <degrees> [freq]` | Переместить ось в угол. freq необязателен, по умолчанию 500 Гц |
| CAL | `CAL <axis> <steps_per_degree>` | Задать калибровочный коэффициент |
| LIMITS | `LIMITS <axis> <min_deg> <max_deg>` | Задать допустимый диапазон углов |
| ZERO | `ZERO <axis>` | Текущую позицию считать нулём |
| HOME | `HOME <axis> [freq]` | Переместить в 0° (нейтраль). Эквивалент ANGLE axis 0 |

Ответы:
- `OK\n` — команда принята
- `DONE <axis>\n` — движение завершено (как раньше)
- `ERR LIMIT <axis> <angle> <min> <max>\n` — угол вне допуска
- `ERR ...` — прочие ошибки (как раньше)

### 3. Обновить STATUS

В ответ STATUS для каждой оси добавить угол:
```
STATUS <axis> <enabled> <busy> <pos> <angle>\n
```
где angle — текущий угол в градусах с одним знаком после запятой (например, `15.3` или `-7.0`). До калибровки angle = pos (1 шаг = 1 градус по умолчанию).

### 4. Обновить LCD

На экране для каждой оси показывать угол вместо (или рядом с) позиции в шагах:
```
Axis 0  ENABLED   IDLE
  angle: +15.3°   pos: +306
```

## Чего НЕ делать

- Не делать автоматический поиск нуля (концевик, homing) — это позже, если понадобится
- Не сохранять калибровку в Flash — пока только в RAM, задаётся при каждом включении
- Не делать acceleration ramp

## Критерий приёмки

- Чистая сборка (0 errors, 0 warnings)
- Команды ANGLE, CAL, LIMITS, ZERO, HOME работают (парсер разбирает)
- STATUS показывает угол
- LCD показывает угол
