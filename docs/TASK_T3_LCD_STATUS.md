# TASK_T3_LCD_STATUS — AeroStand: отображение состояния осей на LCD

## Контекст

T2 закрыт (f15f9c4). Прошивка управляет 3 осями через USB CDC команды (MOVE/STOP/ENABLE/DISABLE/STATUS/PING). Экран TFT 2.4" (240×320, QVGA) на F429I-DISC1 пока не задействован.

## Что сделать

### 1. Инициализация LCD

Использовать BSP-драйвер из STM32Cube (stm32f429i_discovery_lcd). Библиотека работает через LTDC + SDRAM (IS42S16400J на DISC1). Ориентация — портретная (240×320) или ландшафтная (320×240) — на усмотрение, что удобнее для трёх осей.

### 2. Экран состояния (основной и единственный пока)

Отображать в реальном времени (обновление 5–10 раз в секунду):

```
        AeroStand v0.1
─────────────────────────────
 Axis 0  [ENABLED]  IDLE
   pos: +01250  dir: CW

 Axis 1  [DISABLED]  ---
   pos: +00000  dir: --

 Axis 2  [ENABLED]  MOVING
   pos: -00340  dir: CCW
   freq: 1000 Hz  rem: 1660
─────────────────────────────
 USB: Connected
```

Для каждой оси показывать:
- Номер оси
- Состояние драйвера: ENABLED / DISABLED (цветом: зелёный / серый)
- Состояние движения: IDLE / MOVING (MOVING — жёлтым или оранжевым)
- Позиция в шагах (знаковая, из stepper_get_pos)
- Направление: CW / CCW (или -- если idle)
- Для движущейся оси: частота и оставшиеся шаги

Внизу — статус USB (Connected / Not configured).

### 3. Модуль lcd_status.c / lcd_status.h

- `lcd_status_init()` — инициализация LCD, отрисовка статического фрейма (заголовок, разделители)
- `lcd_status_update()` — обновление динамических полей. Вызывается из `while(1)` в main.c, не чаще 10 раз/с (проверка по HAL_GetTick)
- Перерисовывать только изменившиеся поля (не весь экран каждый раз — мерцание)

### 4. Шрифт

Использовать встроенные шрифты BSP (Font16 или Font20). Мелкие детали вроде кастомного шрифта — не сейчас.

## Чего НЕ делать

- Не делать тачскрин-управление — пока только отображение
- Не делать меню или переключение экранов
- Не делать acceleration ramp — это T4

## Критерий приёмки

- Чистая сборка (0 errors, 0 warnings)
- Модули lcd_status.c/h добавлены
- LCD инициализируется, статический фрейм рисуется
- Динамические поля обновляются из данных stepper-модуля
- Коммит и push
